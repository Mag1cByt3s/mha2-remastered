# AGENTS.md — Contributor & Agent Guide

Guidance for coding agents working on the **Moorhuhn Adventure 2: Der Fluch des Goldes — Native Linux x86_64 Remastered Engine**.

> `CLAUDE.md` is a symlink to this file so all agent configurations read one source of truth.

---

## 1. Project Overview

- **What this is:** A standalone static x86 → C recompilation of the original 2005 Windows game `mha2.exe` (`recomp/lift.py`) paired with a clean-room Win32/DirectX/OpenGL 3.3 Core Remastered v5.2 runtime (`runtime/`).
- **Game assets:** Loaded dynamically at runtime from user-supplied `game_files/` (`mha2.dat`, `mha2.exe`, `*.avi`) and 4K WebP/MP4 packs in `hd_assets/`.
- **Active branch:** `main`

## 2. Environment & Build Commands

### NixOS Host Notes
- `/` and `/var/tmp` are mounted on a small **1 GB `tmpfs`**, while `/home` has large disk capacity (`zroot/home`) and `/tmp` is 16 GB.
- Always keep temporary container/build staging under `work/` (e.g., `TMPDIR="$ROOT/work/tmp"` as done in `tools/package_portable_linux.sh`), never `/var/tmp`.

### Native Build & Re-Lifting
- **Build native binary (`./mha2_linux`):**
  ```bash
  nix-shell --run "make -j$(nproc)"
  ```
- **Re-lift `game_files/mha2.exe` into `recomp/gen/` and rebuild** (required after editing `recomp/lift.py`):
  ```bash
  nix-shell --run "make lift && make -j$(nproc)"
  ```
- **Run locally:**
  ```bash
  ./play.sh
  ```

### Portable Linux Release Build (`work/dist/`)
- Built inside an **Ubuntu 22.04** (`glibc 2.35`) builder container defined in `tools/Containerfile.portable` using `podman` (or `docker`), outputting object files to `work/build_portable/` so local NixOS `./build/` and `./mha2_linux` are untouched:
  ```bash
  bash tools/package_portable_linux.sh              # stages bundle + builds .tar.gz (~5.4 GB)
  bash tools/package_portable_linux.sh --no-archive # stages bundle + runs ABI checks without tarballing
  ```
- **Never bundle NixOS `.so` libraries, `libSDL3.so.0`, or `SDL_DYNAMIC_API` in portable releases:** Nixpkgs binaries/libs pull `GLIBC_2.42`, `GLIBCXX_3.4.32`, `CXXABI_1.3.15`, unversioned `DT_NEEDED: libvulkan.so`, Nixpkgs `libstdc++`, and hardcoded `/nix/store` paths, breaking Ubuntu/Mint/Fedora/SteamOS.
- Keep minimal static FFmpeg (`--prefix=/opt/ffmpeg-min` built with `nasm` SIMD) and verified ABI/font checks inside `tools/package_portable_linux.sh` (max `GLIBC_2.35`, zero `/nix/store` strings, zero hard `DT_NEEDED` on `libvulkan.so`/`libpipewire`/`libpulse`/`libwayland`/`libEGL`/`libgbm`/`libdecor`, bundled `fonts/DejaVu*.ttf`).

## 3. Repository & Architecture Map

### Static Recompiler (`recomp/`)
- `recomp/lift.py`: Standalone x86-32 PE → C static lifter (uses `capstone` + `pefile`-free PE parser; discovers 8,134 functions & 121 switch tables, emits `recomp/gen/chunk_*.c`, `dispatch.c`, `funcs.h`, `imports.h`).
- `recomp/gen/`: Generated C translation units (gitignored; regenerated by `make lift`).

### Native Runtime (`runtime/`)
- `runtime/main.c`: CLI argument parsing, `mha2_settings.ini` load ordering, guest Core 0 affinity pinning (`runtime_unpin_current_thread()`), entry point.
- `runtime/cpu.c`, `runtime/cpu.h`: 32-bit guest flat memory (`mmap`), 24-bin segregated free-list `guest_alloc()`, Win32 stdcall/cdecl dispatch, x87 FPU stack emulation.
- `runtime/runtime.h`: Shared `EngineConfig g_cfg`, guest/runtime state declarations, cross-module hooks.
- `runtime/win32_kernel.c`: Win32 threads, events/semaphores/mutexes, handles, case-insensitive VFS/save paths, file I/O, timers.
- `runtime/win32_ddraw.c`: DirectDraw 7 surfaces, hardware-accelerated/emulated blits, RLE sprite hooks (`hook_rle_both`, `hook_rle_common`), `surface_blt()`, palette/color-key conversion, decoupled cursor tracking.
- `runtime/hd_assets.c`, `runtime/hd_assets.h`: `HDS5` 24×24 signature matching, 4K WebP background & sprite index caches (`.hd_index.cache`, `.hd_sprite_index.cache`), strip cell auto-discovery (`hd_sprites_find_strip_cell()`), background preloader thread, sprite room allowlisting (`sprite_allowed_in_active_room()`).
- `runtime/gl_renderer.c`, `runtime/gl_renderer.h`: OpenGL 3.3 Core renderer, 4K HD canvas FBO, shaders (Bicubic CAS, Lanczos, Edge Smooth, FSR1, CRT, Bloom, Color Grading), widescreen `16:10`/`16:9` HUD/dialog split composition, `F1` interactive settings menu, `Ctrl+L` Dialog Log, vector typography (`SDL2_ttf`), GPU post-FX & compare split-screen (`F2`), decoupled cursor, hotspot overlay.
- `runtime/game_patches.c`: Original 2005 game bugfixes (spinlock CPU burn, savegame EOF hang, loading sleep throttle, null derefs, handle leaks), hot-path native replacements, and exact read-only scene-graph hotspot collector (`game_collect_room_hotspots()`).
- `runtime/win32_user_gdi.c`: SDL2 window/event loop, input state, GDI font/TextOutA hooking (Windows-1252 → UTF-8), gamepad cursor emulation.
- `runtime/win32_dinput.c`: DirectInput keyboard/mouse COM stubs.
- `runtime/win32_dsound.c`: DirectSound mixing + SDL2 audio callback + reverb/EQ DSP.
- `runtime/win32_avi.c`: FFmpeg-backed DirectShow (`IGraphBuilder`/`IMediaControl`/`IMediaEventEx`/`IVideoWindow`/`IBasicVideo`) & `AVIFIL32`/`DrawDibDraw` video playback with automatic `hd_assets/videos/*.mp4` 4K override.

### Tooling (`tools/`)
- `tools/Containerfile.portable`, `tools/package_portable_linux.sh`: Self-contained Ubuntu 22.04 portable Linux builder & packager.
- `tools/extract_game.py`, `tools/extract_assets.py`: Legal-copy installer/disc extractor and `mha2.dat` VDrv/`_img`/IT3 unpacker.
- `tools/upscale_transformer.py`, `tools/upscale_alpha_sprites.py`, `tools/remaster_videos_4k.py`, `tools/polish_cursors.py`, `tools/compress_hd_lossless.py`: 4K AI upscaling, IT3 `tbl1+tbl2` compositing, SDF cursor polishing, lossless WebP recompression.
- `tools/install_desktop.sh`, `play.sh`: Local NixOS launcher & `.desktop` installer.

## 4. Key Technical Invariants & Pitfalls (Do Not Break)

1. **Animated JPEG Filmstrip Sprites (`img_type == 0`, `nf > 1`):**
   - Never upscale multi-frame JPEG vertical filmstrips as a single image (`objKerzen`, `gsNormal`, `objBrunnen`, etc.) — neural models bleed adjacent frames into dark horizontal trenches that blink on animation boundaries.
   - Always split and upscale per-frame with edge-replicate padding into `_f000.webp`..`_f{N-1}.webp` (`tools/upscale_transformer.py --apply-jpeg-strips`), and keep `--apply-backgrounds` skipping `nf > 1`.

2. **Split-Background Outdoor Rooms (`l/011`, `l/014`, `l/022`, `l/023`, `l/026`, `l/027`, `l/028`, `l/036`):**
   - In `sprite_allowed_in_active_room()` (`runtime/hd_assets.c`), the allowlist for `/objBgO`, `/objBgU`, `/mskBg.`, and `/objWolken` **must stay before** `if (g_spr_room_prefix_len > 0)`.
   - `maybe_lock_split_room_from_sprite()` (`runtime/win32_ddraw.c`) may lock room state only from `/objBgO`, `/objBgU`, or `/mskBg.` — **never** from shared desert clouds `/objWolken`.
   - Keep `lookup_rle_both_sprite()` max width `>= 2048` (`l/023/img/mskBg` is `1600×212`).

3. **HD Asset Caches (`.hd_index.cache`, `.hd_sprite_index.cache`):**
   - Adding, replacing, or deleting files in `hd_assets/` requires invalidating/rebuilding `.hd_index.cache` and/or `.hd_sprite_index.cache` (or ensuring cache mtime/generation invalidates them).

4. **Guest Core 0 Pinning & Win32 Handle Refcounting:**
   - The original 2005 binary uses non-atomic refcounts across main, loading, and processing threads; guest threads must stay pinned to Core 0 while native worker threads (audio callback, HD pre-decoder) call `runtime_unpin_current_thread()`.
   - When accessing `WinHandle` payloads (`SyncObj` or `ThreadObj`) in `runtime/win32_kernel.c`, always lock `g_hdl_mtx`, extract the pointer strictly matching `htype`, atomically increment `refcount` **before** unlocking `g_hdl_mtx`, and unref afterward.

5. **COM Vtable Slot Accuracy & Lifter Quirks:**
   - Every DirectShow / DirectDraw / DirectSound / DirectInput COM slot must match its exact Windows vtable index (`byte_offset / 4`) and stdcall parameter count (including `this`); wrong counts corrupt guest `ESP`. Check lifted call sites in `recomp/gen/` when implementing slots.
   - Capstone returns 2 operands `[ST(0), ST(i)]` for `fxch D9 C8+i` even though Intel syntax displays `fxch st(i)` for many instructions; verify any new `recomp/lift.py` mnemonic handler directly against Capstone's `ins.operands` output and inspect regenerated `recomp/gen/`.

6. **Hotspot Highlights & Widescreen Dialogs:**
   - `Space`/`H` hotspot highlights must come from `game_collect_room_hotspots()` in `runtime/game_patches.c`, not sprite-name guesses.
   - In `16:10`/`16:9` widescreen modes, bottom dialog choices reach `y=525..536` (`update_hud_bar_masks()`, `uDialogBar`) — keep dialog bar detection, shader UV remapping, and pointer coordinate mapping synchronized.

## 5. Coding, Testing & Git Conventions

- **Compiler strictness:** All `runtime/*.c` files must compile cleanly with **zero warnings** under `-Wall -Wextra`.
- **Code hygiene:** Avoid duplicating logic; keep helpers small and single-purpose; preserve existing docstrings and unrelated comments.
- **No copyrighted / generated commits:** Never commit files matching `.gitignore` (`game_files/`, `hd_assets/`, `work/`, `recomp/gen/`, `build/`, `mha2_linux`, `mha2_settings.ini`, `tools/models/`, `*.exe`, `*.dat`, `*.avi`, `*.sav`).
- **Git commit identity:** Use your configured Git identity (no hardcoded local names or placeholder emails):
  ```bash
  git commit -m "..."
  ```
- **Verification before claiming done:** Rebuild after edits (`nix-shell --run "make -j$(nproc)"`, plus `make lift` if `recomp/lift.py` changed) and inspect generated output / runtime logs / ABI checks directly.
